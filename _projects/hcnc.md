**Status:** Active — ad hoc data supervision; delivering HISCO codes as clean occupational data arrives

The Nordic countries hold some of the richest historical administrative data in the world, but occupational records across countries and centuries use inconsistent classification schemes. The HCNC project builds a unified, standardized occupational dataset for Denmark, Sweden, Norway, and Finland using OccCANINE.

The result is a data infrastructure for comparative research on human capital, labor markets, and structural change across the Nordic region.
